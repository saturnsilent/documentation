# Configuration Tebex

> Comment relier votre boutique Tebex à votre serveur, étape par étape.

## C'est quoi cette page ?

Pour que votre boutique en ligne (Tebex) puisse fonctionner avec votre serveur, il faut renseigner **un seul champ** : `server_username`. Ce champ sert à dire à Tebex "voici mon serveur, connecte-toi à lui".

Pas besoin de taper de commande ni de toucher au code : tout se fait dans le panel Tebex, avec la souris.

![Configuration Tebex](https://addcdn.rf.gd/uploads/1778791907_tebexconfig.png)

---

## Ce qu'il faut savoir avant de commencer

| Ce qu'on vous demande | Réponse |
| --- | --- |
| Nom du champ à remplir | `server_username` |
| Type de champ | Du texte simple |
| Longueur minimum | 3 caractères (lettres/chiffres) |
| Longueur maximum | 50 caractères |

---

## Quels caractères je peux utiliser ?

<CardGroup cols={2}>
  <Card title="Lettres" icon="a">
    A à Z, en majuscules ou minuscules (ex: `Bob`, `bob`, `BOB`)
  </Card>
  <Card title="Chiffres" icon="0">
    0 à 9 (ex: `123`)
  </Card>
  <Card title="Espaces" icon="pause">
    Vous pouvez mettre des espaces (ex: `Mon Serveur`)
  </Card>
  <Card title="Symboles autorisés" icon="star">
    `? ! . , - ( ) $ £ € @ % & * §`
  </Card>
</CardGroup>

<Warning>
  Si votre texte est trop court (moins de 3 caractères) ou trop long (plus de 50), Tebex refusera de l'enregistrer. Vérifiez bien avant de valider.
</Warning>

## Étape par étape : remplir le champ `server_username`

<Steps>
  <Step title="1. Ouvrez votre panel Tebex">
    Connectez-vous à votre compte Tebex, comme d'habitude.
  </Step>
  <Step title="2. Allez dans la section Variables">
    Dans le menu, cherchez et cliquez sur **Variables**. C'est là que se trouve `server_username`.
    ![Configuration Tebex](https://addcdn.rf.gd/uploads/1778791907_tebexconfig.png)
  </Step>
  <Step title="3. Écrivez votre nom d'utilisateur serveur">
    Cliquez dans la case vide et tapez le nom que vous voulez donner à votre serveur.
    Rappel : entre 3 et 50 caractères, pas plus, pas moins.
  </Step>
  <Step title="4. Cliquez sur Update">
    Un bouton **Update** se trouve en bas ou à côté du champ. Cliquez dessus pour enregistrer.
    C'est fini, la configuration générale est faite !
  </Step>
</Steps>

---

## Deuxième étape : le faire aussi pour chaque package (produit en vente)

Attention : la config ci-dessus ne suffit pas toute seule. Il faut **refaire la même chose pour chaque produit** que vous vendez sur votre boutique (chaque "package").

![Configuration du package Tebex](https://addcdn.rf.gd/uploads/1780247744_tebeximage.png)

<Steps>
  <Step title="1. Ouvrez le produit concerné">
    Dans votre panel Tebex, cliquez sur le package (le produit) que vous voulez configurer.
  </Step>
  <Step title="2. Allez dans Variables">
    Toujours dans ce produit, cliquez sur l'onglet **Variables**. C'est le même endroit où vous réglez le prix du produit.
  </Step>
  <Step title="3. Remplissez la valeur">
    Écrivez la valeur demandée, comme à l'étape précédente. Rien d'autre à faire.
  </Step>
</Steps>

<Note>
  Aucune commande à taper. Aucun code à écrire. Juste remplir la case, comme un formulaire. Tebex fait le lien automatiquement avec votre serveur.
</Note>

---

## Un souci ?

- **"C'est refusé"** → vérifiez que votre texte fait bien entre 3 et 50 caractères, et que vous n'utilisez pas un symbole interdit.
- **"Je ne trouve pas la section Variables"** → elle se trouve au même endroit que le prix du produit, dans les paramètres du package.
