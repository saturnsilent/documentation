## Introduction au panel Addveo

<Info>
  Le panel **Addveo** centralise l’administration de votre serveur dans une seule interface.\
  Vous pilotez l’exploitation, la configuration et le suivi sans multiplier les outils.
</Info>

![Aperçu du panel Addveo](https://addcdn.rf.gd/uploads/panneladdveo/1777582743_Capture_d___cran_2026-04-30_225850.png)

_Le panel regroupe les actions clés dans une interface unique._

### Ce que permet le panel

- Superviser l’état général du serveur.
- Accéder rapidement aux modules de gestion.
- Suivre les actions récentes et les événements importants.
- Ajuster les paramètres utiles à l’exploitation quotidienne.

### Ce que couvre cette documentation

Cette documentation détaille chaque zone du panel avec une approche simple.\
Vous y trouverez les fonctions disponibles, leur logique et leur usage concret.

<Info>
  Pour une prise en main plus fluide, commencez par le **Dashboard**, puis avancez vers les sections spécialisées.
</Info>
