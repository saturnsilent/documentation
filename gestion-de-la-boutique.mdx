## Vue d'ensemble

<Info>
  La boutique centralise les offres, les paramètres commerciaux et le suivi des ventes. Chaque produit est configurable indépendamment — contenu, prix, rareté, limites d'achat et mise en avant commerciale.
</Info>

## Créer un produit

<Steps>
  <Step title="Ouvrir le formulaire">
    Depuis l'interface, cliquez sur l'action de création pour ouvrir le formulaire de configuration.

    ![Ajout d'un produit boutique](https://addcdn.rf.gd/uploads/1777587068_Design_sans_titre__49_.jpg)
  </Step>
  <Step title="Renseigner les paramètres">
    Complétez les informations suivantes :

    ![Paramètres d'un produit boutique](https://addcdn.rf.gd/uploads/1777587163_Design_sans_titre__51_.jpg)

    | Paramètre | Description |
    | --- | --- |
    | **Nom / Description** | Informations visibles par le joueur dans la boutique |
    | **Type** | Nature de la récompense : item, véhicule, arme, etc. |
    | **Prix (tokens)** | Coût d'achat du produit |
    | **Daily Shop** | Produit exclusif ou chance d'apparition dans la rotation |
    | **Limites** | Restriction d'achat par joueur, ex. `1 par personne` |
    | **Stock** | Quantité disponible — limitée ou illimitée |
    | **Badge** | Mise en avant commerciale, ex. `Best Seller`, `Nouveau` |
    | **Contenu** | Objet délivré et quantité associée à l'achat |
  </Step>
  <Step title="Sauvegarder">
    Cliquez sur le bouton **Sauvegarder** en haut à droite pour appliquer les modifications.

    <Warning>
      Les changements ne sont pas automatiquement appliqués — toute modification non sauvegardée sera perdue.
    </Warning>
  </Step>
</Steps>

## Comprendre le Daily Shop

Le mode **Daily Shop** permet de faire tourner des offres temporaires sans modifier l'ensemble du catalogue.

<CardGroup cols={2}>
  <Card title="Créer de la rareté" icon="clock-rotate-left">
    Un produit en rotation n'est pas toujours disponible — ce qui incite les joueurs à revenir régulièrement.
  </Card>

  <Card title="Renouveler la boutique" icon="arrows-rotate">
    Le catalogue reste frais sans ajout permanent de nouveaux produits.
  </Card>
</CardGroup>

## Statistiques de vente

<Steps>
  <Step title="Accéder aux statistiques">
    Un onglet dédié affiche les ventes en temps réel pour piloter votre offre commerciale.

    ![Statistiques de vente](https://addcdn.rf.gd/uploads/1777641003_Design_sans_titre__17_.jpg)
  </Step>
  <Step title="Analyser les tendances">
    Consultez le détail des performances par produit.

    ![Détail des statistiques boutique](https://addcdn.rf.gd/uploads/1777587911_Design_sans_titre__53_.jpg)
  </Step>
  <Step title="Affiner votre offre">
    Utilisez les données pour ajuster votre catalogue.

    ![Vue complémentaire des statistiques](https://addcdn.rf.gd/uploads/1777588136_Design_sans_titre__54_.jpg)

    Ces données permettent de :

    - repérer les produits les plus performants ;
    - ajuster les prix en fonction des tendances ;
    - mesurer l'impact économique d'une offre avant de la retirer ou la modifier.

    <Tip>
      Consultez les statistiques **avant tout changement de prix** — une baisse peut suffire à relancer un produit stagnant.
    </Tip>
  </Step>
</Steps>

## Recommandations

<Warning>
  Limitez les offres trop puissantes — un produit déséquilibré peut dégrader l'économie du serveur durablement.
</Warning>

- Soignez les descriptions et les visuels pour chaque produit.
- Surveillez régulièrement le stock et les limites d'achat.
- Appuyez-vous sur les statistiques avant toute modification tarifaire.
