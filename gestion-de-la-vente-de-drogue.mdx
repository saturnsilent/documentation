## Vue d'ensemble

<Info>
  Le système de vente de drogue s'articule autour de deux éléments : les **grossistes** qui définissent les points de contact et les substances proposées, et les **territoires** qui répartissent les zones de vente sur la carte.
</Info>

## Grossistes

Les grossistes sont les PNJs avec lesquels les joueurs interagissent pour vendre. Chaque grossiste est lié à un type de drogue spécifique.

<Steps>
  <Step title="Accéder à la liste">
    Consultez les grossistes existants ou créez-en un nouveau.

    <img
      src="https://addcdn.rf.gd/uploads/1777592170_Design_sans_titre__49_.jpg"
      alt="Configuration des grossistes"
      style={{ width: "70%" }}
    />
  </Step>
  <Step title="Renseigner les champs">
    Complétez les informations suivantes :

    <img
      src="https://addcdn.rf.gd/uploads/1777592685_Design_sans_titre__53_.jpg"
      alt="Formulaire d'un grossiste"
      style={{ width: "68%" }}
    />

    <img
      src="https://addcdn.rf.gd/uploads/1777592612_Design_sans_titre__52_.jpg"
      alt="Paramètres d'un grossiste"
      style={{ width: "73%" }}
    />

    | Champ | Description |
    | --- | --- |
    | **Nom** | Identifiant du grossiste dans la liste |
    | **Modèle du PED** | Apparence du personnage en jeu |
    | **Type de drogue** | Substance associée à ce point de vente |
  </Step>
</Steps>

## Territoires

Les territoires délimitent les zones de vente sur la carte et peuvent chacun contenir plusieurs points de génération.

<Steps>
  <Step title="Accéder à la liste des territoires">
    Consultez les territoires configurés sur le serveur.

    <img
      src="https://addcdn.rf.gd/uploads/1777592378_Design_sans_titre__50_.jpg"
      alt="Liste des territoires"
      style={{ width: "72%" }}
    />
  </Step>
  <Step title="Ouvrir la fiche d'un territoire">
    Cliquez sur un territoire pour accéder à sa fiche de gestion.

    <img
      src="https://addcdn.rf.gd/uploads/1777592450_Design_sans_titre__51_.jpg"
      alt="Gestion d'un territoire"
      style={{ width: "78%" }}
    />

    | Option | Description |
    | --- | --- |
    | **Nom** | Modifier le nom du territoire |
    | **ID** | Consulter l'identifiant interne |
    | **Téléportation** | Se rendre directement sur place pour vérifier le placement |
    | **Générateurs** | Gérer les points de génération — plusieurs positions possibles par territoire |
  </Step>
</Steps>

## Recommandations

<Tip>
  Vérifiez les positions des générateurs **directement en jeu** après configuration — un générateur mal placé peut bloquer les interactions ou sortir de la zone prévue.
</Tip>

- Répartissez les territoires de façon **équilibrée** sur la carte pour éviter les concentrations.
- Donnez des noms **clairs et géographiquement cohérents** aux zones.
- Évitez de concentrer trop de générateurs sur une seule zone de la map.
