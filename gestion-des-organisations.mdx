## Vue d'ensemble

<Info>
  Les organisations regroupent les structures criminelles ou factionnelles du serveur. Chaque organisation dispose de ses propres points d'accès, d'une faction associée et d'options de visibilité configurables indépendamment.
</Info>

## Créer une organisation

<Steps>
  <Step title="Ouvrir le formulaire">
    Cliquez sur **Créer une organisation** pour ouvrir le formulaire de configuration.

    <img
      src="https://addcdn.rf.gd/uploads/1777591745_Design_sans_titre__45_.jpg"
      alt="Paramètres d'une organisation"
      style={{ width: "65%" }}
    />
  </Step>
  <Step title="Renseigner les champs">
    Complétez les informations suivantes :

    | Champ | Description |
    | --- | --- |
    | **Nom** | Identifiant de l'organisation visible en jeu |
    | **Capacité** | Nombre maximum de membres |
    | **Modèle du recruteur** | Apparence du PNJ de recrutement |
    | **Faction** | Type d'organisation : `Cartel`, `Mafia`, etc. |
    | **Couleur** | Couleur associée à l'organisation sur la carte |
    | **Position du recruteur** | Coordonnées du PNJ de recrutement |
    | **Position du vestiaire** | Point de changement de tenue des membres |
    | **Position du coffre** | Stockage dédié à l'organisation |
  </Step>
  <Step title="Configurer les options globales">
    Ajustez les options de visibilité et les mécaniques spécifiques.

    <img
      src="https://addcdn.rf.gd/uploads/1777591903_Design_sans_titre__46_.jpg"
      alt="Options d'organisation"
      style={{ width: "56%" }}
    />

    | Option | Description |
    | --- | --- |
    | **Afficher les QG sur la map** | Active les blips des QG sur la carte du joueur concerné |
    | **Obtenir la recette de meth** | Affiche la recette de fabrication associée à l'organisation |

    <Info>
      L'affichage des QG est **personnel** — seul le joueur ayant activé cette option les voit sur sa propre carte.
    </Info>
  </Step>
</Steps>

---

## Recommandations

<Tip>
  Vérifiez la visibilité des QG en jeu avec un compte membre avant de diffuser l'organisation aux joueurs.
</Tip>

- Définissez une capacité **cohérente avec votre gameplay** — trop large dilue la dynamique de faction.
- Utilisez les **factions** pour structurer clairement vos organisations entre elles.
- Placez les points d'accès dans des zones **testées et dégagées** avant mise en production.
