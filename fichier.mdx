## Configuration des Modules

Les fichiers de configuration permettent de contrôler entièrement le fonctionnement d'un module sans toucher à la logique principale du script.

<CardGroup cols={2}>

## Modifier un paramètre

Vous pouvez ajuster :

- les **valeurs globales** — durée, activation, etc.
- les **positions** — `vector3`, `vector4`
- les **objets ou éléments** dans les listes

Pour ajouter un nouvel élément, copiez une structure existante, modifiez uniquement les valeurs nécessaires et conservez les mêmes clés.

## Commandes utiles

| Commande | Description |
| --- | --- |
| `/copyc` | Copie la position actuelle en `vector3` |
| `/copych` | Copie la position actuelle en `vector4` (avec orientation) |

## Bonnes pratiques

Ne modifiez jamais les **noms des clés** — le script les lit de manière exacte. Une coquille suffit à casser le module.

<Tip>
  Réutilisez toujours une structure existante comme base et testez en jeu après **chaque modification individuelle**.
</Tip>

- Respectez le format des données (`vector3`, `vector4`, nombres…).
- Vérifiez les virgules et accolades `{}` après chaque modification.
- Évitez de supprimer des éléments sans vérifier leur utilité au préalable.
- Évitez les modifications massives sans validation progressive.
